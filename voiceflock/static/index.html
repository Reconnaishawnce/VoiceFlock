Phone app

Listens offline and performs the alert when a flagged voice (🔔 on a person) is heard. Install with Obtainium from github.com/Reconnaishawnce/VoiceFlock.

Simplest: Download phone library (.json), send it to the phone (WhatsApp, email, Drive), open it with VoiceFlock. The phone fetches the speaker model from GitHub itself. Re-send the file whenever you flag or name voices.

Hands-free: set Auto-export phone library to (below) to a folder that syncs to the cloud (Dropbox, Google Drive, OneDrive). The file is rewritten whenever voices or alerts change. Share that file's link once, paste it into the app's Settings → Library URL, and the phone re-downloads it on its own.

Model self-test
        
Loads both models on 8 s of synthetic audio. Run once after setting the token.

        
 

        

      

      
Danger zone: wipe the library
        
Deletes every recording, voice, print, package, alert flag, feed and all converted audio, clips and stills. Settings (including your HuggingFace token), calibration and downloaded models stay. This cannot be undone; export first if in doubt.

        

        

      

      
Name suggestions
        
After a recording is processed, VoiceFlock reads on-screen captions, the title and description, and who was introduced or addressed in the transcript, and asks a language model to weigh them. Suggestions appear as chips next to the name box; nothing is named automatically. Settings for this are under Name suggestions above.

        

      

      
Probability calibration
        
Every Confirm, Name, Enroll and Reject you make is a labelled trial. Fitting the probability model to them makes the percentages mean something for your microphones and rooms, instead of generic constants.
