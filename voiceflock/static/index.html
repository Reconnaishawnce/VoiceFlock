Phone app

      
The Android app listens offline and alerts when a flagged voice (🔔 on a person) is heard. Install it with Obtainium from github.com/Reconnaishawnce/VoiceFlock.

      
Simplest: Download phone library (.json), send it to the phone (WhatsApp, email, Drive) and open it with VoiceFlock. The phone fetches the 85 MB speaker model from GitHub by itself. Re-send the file whenever you flag or name voices.

      
Or sync directly over Wi-Fi/Tailscale: in the app's Settings enter one of these addresses and press Sync.

Calibration & evaluation

      
Run from the command line (see README): voiceflock calibrate <folder> fits the probability calibration and
        cohort from labelled clips; voiceflock evaluate <folder> reports rank-1 accuracy, EER, DET curve and miss rate at 1% false alarm.
